# Fonts

[Figtree](https://github.com/erikdkennedy/figtree) variable font (`wght` 300–900), roman and italic, from [google/fonts](https://github.com/google/fonts/tree/main/ofl/figtree). SIL Open Font License 1.1, see `OFL.txt`. Loaded by the web client (`web/src/app.css`) and embedded in the server binary with it.

[Source Code Pro](https://github.com/adobe-fonts/source-code-pro) variable font (`wght` 200–900), upright only, from [google/fonts](https://github.com/google/fonts/tree/main/ofl/sourcecodepro) (upstream commit `803b7e2`). SIL Open Font License 1.1 with the Reserved Font Name "Source", see `SourceCodePro-OFL.txt`; the file is bundled unmodified, so the name may stay. The `type.code` face for inline code and code blocks (DESIGN.md §2.4); the browser downloads it only when code is on screen, and slants it for the rare italic code.

`desktop/` holds the static faces the desktop client embeds (`crates/mellow-desktop/src/theme/fonts.rs`): GPUI's Linux text system registers a variable font as one face at its default weight (Figtree's default is 300, Source Code Pro's 200), so every weight would render thin. The Figtree faces (400, 500, 600, 700 and 800 roman; 400, 600 and 700 italic) are instances of the variable files above, made by `python3 design/fonts/make-desktop-instances.py` (fontTools 4.68); Figtree has no Reserved Font Name. The Source Code Pro faces (Regular, It, Semibold, Bold) are Adobe's static TTFs copied unmodified from the release `2.042R-u/1.062R-i/1.026R-vf` (`TTF-source-code-pro-2.042R-u_1.062R-i.zip`, SHA-256 `0c85bac90d15c040b82939aa92bc8404420fccc02e37bbcb9c93a7f21abb52c6`), so the reserved name "Source" may stay.
