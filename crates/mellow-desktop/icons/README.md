# Icons

[Phosphor Icons](https://phosphoricons.com) 2.1.1 (`@phosphor-icons/core`, MIT, see `LICENSE`), copied as SVG and recoloured in Slint with `colorize` from design tokens.

Weight: **Fill** (DESIGN.md §2.9), except `check.svg`, `hash.svg`, `plus.svg` and `x.svg`, which use **Bold**: their Fill versions are a solid square with the glyph cut out, unlike Discord's open check, channel, add-server and close glyphs.

To add an icon, copy `assets/fill/<name>-fill.svg` from the same package version as `<name>.svg`.
