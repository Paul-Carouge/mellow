# Icons

[Phosphor Icons](https://phosphoricons.com) 2.1.1 (`@phosphor-icons/core`, MIT, see `LICENSE`), copied as SVG and recoloured in Slint with `colorize` from design tokens.

Weight: **Fill** (DESIGN.md §2.9), except `at.svg`, `check.svg`, `hash.svg`, `list.svg`, `plus.svg` and `x.svg`, which use **Bold**: their Fill versions are a solid square or disc with the glyph cut out, unlike Discord's open mention, check, channel, menu, add-server and close glyphs. The web client (`web/`) reads the same files.

To add an icon, copy `assets/fill/<name>-fill.svg` from the same package version as `<name>.svg`.
